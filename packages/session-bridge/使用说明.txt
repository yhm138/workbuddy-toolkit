WorkBuddy 会话桥 · 使用说明
================================

这是什么
--------
给 WorkBuddy 的左侧栏加一个「会话桥」面板，一个地方看全所有会话：

  · 本机正在跑的会话，和昨天那个停在哪儿的会话，列在一起
  · 点开任意一个就能接着问，不用先切窗口再找
  · 想开新会话，直接在里面点「+ 新建」
  · 每个会话都能「复制 ID」，粘到别处引用
  · 顺手带上 7 个技能：翻历史、算 token 花费、盘点配置、迁移自检

如果你以前用过 DeepSeek Harness 的会话列表，就是那个手感。


怎么装（1 分钟）
----------------
1. 双击「一键安装.cmd」

2. 如果弹出「是否允许此应用对你的设备进行更改」，点「是」
   （没弹窗就跳过这一步，很正常）

3. 装完它会问要不要重启 WorkBuddy，直接按回车（回车 = 是）

4. 重启后左侧栏出现「会话桥」，点开就能用

不用装 Node.js —— 用的是 WorkBuddy 自带的运行时。
不用管理员权限 —— 只有你的 WorkBuddy 装在 Program Files 下时才需要
（那就右键「一键安装.cmd」→ 以管理员身份运行）。

它只做两件事：往 WorkBuddy 的扩展目录放一个文件夹，往你的用户目录放 7 个技能。
WorkBuddy 本身的文件一个都不改。


怎么用
------
点开左侧栏的「会话桥」，上面有三类会话可以切：

  本机      你自己电脑上的 WorkBuddy 会话（最常用）
  DSH       如果你装着 DeepSeek Harness，它那边的会话也在这里
  云端      WorkBuddy 账号下的云端会话

点任意一条会话 → 右边就是对话记录 → 下面输入框直接接着问。

  + 新建    开一个新会话，可以顺手填个工作目录和第一句话
  复制 ID   把这个会话的 ID 放进剪贴板
  停止      正在跑的那一轮可以打断
  诊断      面板抽风的时候点它，会列出每一环的状态


我装完没看到面板
----------------
1. 确认真的重启过 WorkBuddy：托盘图标右键 → 退出，等它完全没了再从桌面图标打开
2. 双击「检查状态.cmd」，它会逐项检查并告诉你卡在哪
3. 检查结果显示「侧栏面板 已装」却看不到：再彻底退出重开一次


不想用了
--------
双击「一键卸载.cmd」，再重启 WorkBuddy。

它只删面板和技能。聊天记录、配置、你的项目文件都还在。


出问题了
--------
把「检查状态.cmd」的输出发出来。里面没有隐私内容，只有路径和版本号。


文件都是干什么的
----------------
  一键安装.cmd      装
  一键卸载.cmd      卸
  检查状态.cmd      看状态 / 自我修复
  dsh2wb.cmd        命令行工具，不做开发可以不管

  bin/              程序本体
  extension/        侧栏面板
  skills-pack/      7 个技能
  src/              命令行工具的实现

  README.md         给开发者看的，有原理和排错细节
